# Metro Monsters (Retro Web Arcade Edition)

An 80's style 2D arcade monster city smasher built with just JavaScript, Canvas, and Web Audio. No libraries or frameworks.

---

## What Is This?

Remember classic arcade monster smashers? This is a modern web tribute to them. You play as one of three giant monsters tearing down skyscrapers, eating pedestrians to stay alive, and dodging tanks, cop cars, and attack helicopters while you smash sky scrapers in cities across the world.

### The Roster:
- **Manny**: Giant Gorilla (heavy hitter, maximum punch damage).
- **Liz**: Giant Lizard (agile climber, fast scaling speed).
- **Lyall**: Giant Werewolf (speedy leap & rapid climbing).

---

## How to Play?

### Controls:
- **Player 1 (Solo / Co-Op)**:
  - `A` / `D` — Walk Left / Right
  - `W` — Climb Wall / Up
  - `S` — Face Front / Down
  - `SPACEBAR` — Jump
  - `F` — Punch / Eat Window Civilian
- **Player 2 (Local Co-Op/Online Co-Op in progress)**:
  - `Left` / `Right` Arrow — Walk Left / Right
  - `Up` Arrow — Climb Wall / Up
  - `Down` Arrow — Face Front / Down
  - `M` — Jump
  - `N` — Punch / Eat Window Civilian
- **Game Controls**:
  - `P` / `ESC` — Pause / Resume
  - `CRT Button` — Toggle Retro CRT Scanlines
  - `SOUNDS / MUSIC` — Toggle Audio & Synth BGM

Gamepad controls are also supported for both players. (or at least in testing for it)
